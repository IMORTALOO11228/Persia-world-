# Persia World

نسخه‌ی آغازین پروژه‌ی دانشنامه‌ی تعاملی تاریخ و تمدن ایران.

## اجرا
فایل `index.html` را در مرورگر باز کنید. برای نمایش صحیح فونت‌ها، اتصال اینترنت لازم است.

## ساختار
- `index.html`: صفحه‌ی اصلی
- `timeline.html`: خط زمانی مقدماتی
- `dynasties.html` تا `scientists.html`: هشت بخش دانشنامه
- `sources.html`: منابع و شیوه‌ی پژوهش
- `css/style.css`: طراحی و واکنش‌گرایی
- `js/data.js`: داده‌های اولیه
- `js/main.js`: تعاملات و رندر کارت‌ها

## انتشار با GitHub Pages
1. فایل‌ها را در ریشه‌ی مخزن GitHub بارگذاری کنید.
2. وارد Settings > Pages شوید.
3. در بخش Build and deployment، گزینه‌ی Deploy from a branch را انتخاب کنید.
4. شاخه‌ی `main` و پوشه‌ی `/(root)` را انتخاب و Save کنید.
5. پس از اتمام انتشار، نشانی سایت در همان صفحه نمایش داده می‌شود.

راهنمای رسمی: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## نکته‌ی پژوهشی
مدخل‌ها و تاریخ‌های این نسخه نمونه و مقدماتی‌اند. پیش از انتشار عمومی، هر ادعای تاریخی باید با مقاله‌ی اختصاصی ویکی‌پدیای فارسی بررسی شود. برای متن و تصویر، انتساب و مجوز هر مورد را جداگانه رعایت کنید.
